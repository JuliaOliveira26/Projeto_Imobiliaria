
## Para que serve cada pasta?

| Pasta | Função |
|---|---|
| `pages/` | Armazena todas as páginas do site, cada uma com seu próprio HTML, CSS e JavaScript. |
| `components/` | Contém elementos reutilizados em várias páginas, como header, footer, cards e modais. |
| `assets/` | Armazena imagens, ícones, fontes e outros arquivos visuais. |
| `shared/css/` | Contém os estilos globais compartilhados entre as páginas. |
| `shared/js/` | Armazena funções JavaScript compartilhadas entre diferentes páginas. |
| `shared/data/` | Guarda os dados dos imóveis utilizados no projeto. |
| `shared/utils/` | Contém funções auxiliares, como validações, formatações e manipulação de dados. |
